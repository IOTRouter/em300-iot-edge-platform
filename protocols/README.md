
# EM300 Industrial Protocol Integration

The IOTRouter EM300 Industrial Edge Controller supports communication and data integration with a wide range of industrial automation devices.

It provides connectivity for PLCs, CNC machines, meters, and other industrial equipment through Ethernet and serial communication interfaces.

## Supported Device Categories

### PLC Integration

Connect PLCs from major industrial automation manufacturers using supported communication protocols.

[View Supported PLC Protocols](./plc-protocols.md)

### CNC Integration

Collect data from CNC systems across multiple manufacturers and controller series.

[View Supported CNC Systems](./cnc-protocols.md)

## Communication Interfaces

- Ethernet
- RS485 Serial Communication

## Integration Capabilities

- Multi-brand PLC connectivity
- CNC machine data acquisition
- Industrial protocol conversion
- Modbus RTU/TCP communication
- Integration with SCADA and cloud platforms
- Local data processing and automation using Node-RED

For detailed compatibility information, refer to the PLC and CNC documentation above.
