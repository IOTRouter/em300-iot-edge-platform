
# EM300 Supported CNC Systems

The IOTRouter EM300 Industrial Edge Controller supports data communication with CNC systems from major manufacturers through Ethernet and serial interfaces.

Representative CNC models from each brand have been selected for testing. Other supported model information is based on official manufacturer documentation.

## CNC Compatibility List

| Brand | Interface | Supported CNC Models |
|---|---|---|
| SIEMENS | Ethernet | Entire series |
| MELSEC | Ethernet | Entire series |
| FANUC | Ethernet | All series except 18i and 21i |
| FANUC | Serial Port | Entire series |
| HAAS | Ethernet | Entire series |
| BROTHER | Ethernet | Entire series |
| GSK | Ethernet | GSK988 / 980TDI Series |
| GSK | Serial Port | 980T / MDC Series |
| HEIDENHAIN | Ethernet | 530 / 520 Series |
| CITIZEN | Ethernet | Entire series (customized version; contact IOTRouter) |
| KND | Ethernet | Version V4.3 and above |
| MAZAK | Ethernet | Entire series |
| SYNTEC | Ethernet | Version V10.118 |
| LNC | Ethernet | Entire series |

## Communication Interfaces

The EM300 supports CNC integration through:

- Ethernet
- Serial Port

The available interface and supported model depend on the CNC manufacturer and controller version.

For customized compatibility requirements, contact the IOTRouter technical team.
